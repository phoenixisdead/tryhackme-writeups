# tryhackme-writeups

This repository contains my technical write-ups for TryHackMe rooms, documenting hands-on exercises in cybersecurity. The focus is on understanding attack methodologies, defensive concepts, and the reasoning behind each exercise rather than simply solving the room.

## Categories

- AI Security
- SOC Analysis
- Splunk Investigations
- Malware Analysis
- Incident Response
- Threat Hunting

| Room | Category | Skills Demonstrated |
|------|----------|---------------------|
| Investigating with Splunk | SOC | SPL, Log Analysis, Incident Response |
| Input Manipulation & Prompt Injection | AI Security | Prompt Injection, Context Manipulation, LLM Security |
